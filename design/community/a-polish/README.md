# 社区 A 版精做（11/27）

概念图：concept_home.png（首页）、concept_person.png（别人主页）；部件：parts/（GPT 画，cut_parts 抠，未改像素）；GPT 讨论：project/discuss/club-a-polish.md。

## 统一规则：窄栏 = 这一页在讲谁/什么，宽栏 = 内容
| 页面 | 窄栏（左页插卡） | 宽栏（相册） |
|---|---|---|
| 社区首页 | 主题卡 / 本周精选 / 会员证（三张卡各插在一个浅皮袋上） | 大家的作品（或“关注”） |
| 主题页（选另一个主题） | 主题卡换成那个主题 | 那个主题的作品 |
| 本周精选 | 精选卡标为当前 | 精选作品 |
| 别人主页 | “← 回到社区”纸签 + 档案卡（首字章、名字、简介、多用胶卷、关注签、写信签、拉黑） | TA 的作品，顶上索引耳“TA 的照片” |
| 自己主页 | 回到社区 + 档案卡（会员证展开：四个数、本周七格、+N） | 索引耳“我的作品 / 消息”；消息页是原来弹层里的来信、通知、奖励、名单、账户，放进宽栏 |
| 点开作品 | 整左页放大图，右页作者和留言（不再挤在单列） | — |

## 几何（内屏底板约 917×635pt）
- 左栏约 217pt（约屏宽 23%），右边 3 列，每张约 205pt；第 1、2 列之间 24pt 的缝正好压在书脊上：左页 = 插卡 + 第 1 列，右页 = 第 2、3 列。4 列会被书脊切开，所以 3 列。
- 字：正文 15pt，标题 22pt，任何字 ≥11pt；可点 ≥44pt。

## 物件
- 左栏卡片插在缝在毡面上的浅皮袋（皮唇只压卡片空白底边，不压按钮）。
- 作品：奶油相纸卡，对角两枚黑相角（不是四枚，避免 48 个黑点）。
- 筛选：网格上方一条牛皮纸边，“大家/关注”“胶卷”两个纸索引耳从纸边长出来，滚动时固定。
- 个人主页不用弹层：原地换页（窄栏换成档案卡，宽栏换成 TA 的作品），返回恢复原来的范围、筛选和滚动位置。别人的主页不显示粉丝等计数（沿用“无公开计数”）。
