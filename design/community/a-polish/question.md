我的方案：
1. 几何跟书脊绑定。内屏底板约 917×635pt，书脊在正中。左栏约 217pt（约 1/4 屏宽），右边 3 列照片、每张约 205pt 宽、列间 24pt；列 1 和列 2 之间的缝正好落在书脊上——于是左页 = 卡槽栏 + 第 1 列照片，右页 = 第 2、3 列。照片一行横跨两页，像翻开的相册跨页；半折时折痕落在缝里，不切照片。4 列会让书脊切进照片，所以选 3 列。
2. 左栏 = 左页上缝好的“阶梯卡槽”（像皮夹/文件夹内侧的插卡位）：三张卡分别插在三层皮槽里，每张底边被皮槽口压住约 12pt：主题卡（代表图 217×120、主题名、剩余时间、N 人发布、朱红“去发布”签）、本周精选（一张封面+“本周精选 · N 张”）、会员证（首字章、名字、拍摄/获赞/粉丝/关注四个数、朱红 +N 纸签）。不滚动，字 ≥11pt，正文 15pt，可点 ≥44pt。
3. 右边每张作品 = 奶油色相纸卡，四角黑色相角（GPT 部件），下方两行：小首字章+名字，胶卷小标签+♥赞。筛选器（大家/关注、胶卷罐图标+卷名）做成从网格上沿伸出的纸索引耳，滚动时固定。
4. 统一规则：窄栏=“这一页在讲谁/什么”，宽栏=内容。首页：窄栏是三张卡，宽栏是大家的作品；主题页/精选：窄栏的那张卡换成这个主题/精选的说明卡，宽栏是它的作品；个人主页：窄栏换成这个人的“档案卡”（首字章、名字、简介、关键数字、关注签/写信签；自己的就是会员证展开 + 消息、信件、账户入口），宽栏是 TA 的作品，顶上一个“← 回到社区”纸签，返回恢复范围、筛选和滚动位置；自己的页宽栏多一个索引耳“消息与账户”，把现在弹层里的消息/奖励/账户内容放进宽栏。过渡用“翻到本子另一节”：窄栏卡片像被换掉一样翻转，宽栏淡入。点开作品：宽栏原地变成“左大图（列1位置那页）+ 右页文字/留言”的横线纸。
5. 外屏（678×466）：顶部一条横带（主题卡、精选、会员证横排）+ 索引耳 + 3 列；个人主页 = 档案卡横条在上、作品在下。
