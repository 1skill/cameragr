## 胶卷头图
- 胶卷挪出纸卡，直接躺在左页皮面上（缝是割在皮上的），宽度 = 左栏 + 两边各 8pt 边距；下面的卡片在它下面滚动，胶卷不动。
- 尺寸按宽度算到最大：中间一格完整落在两个缝口之间，两边各露约 7pt 邻格；缝口比胶卷高（胶卷 h，缝口开口 h+6），之前胶卷比缝口还高。内屏一格画面约 162×87pt（原约 128×68），面积约 1.6 倍。
- 胶卷压在缝皮的内半边上，到缝口中线消失，进缝的那段渐暗（往下钻）。
- 每 5 秒手拉一格：先收一点松量（往回 3.5%）→ 快拉到 62% → 卡一下 → 再拉到 102.5% → 回弹停在整格。手指碰过就不自动；减少动态效果时不动；截图时不动。
- 精选进胶卷：有本周精选时多一格（片边印 ★），画面是第一张精选；下面的字是“★ 精选 / 本周精选 / N 张”，按钮“看全部 ›”；没有精选不出现。原来单独的精选卡删掉（内屏、外屏都删）。
- 没有封面的主题：读它的第一页，取最新一张公开作品；一张都没有才用漏光空白格。
