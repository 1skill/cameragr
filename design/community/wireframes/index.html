社区页重新设计：框架图

11 月 27 日 · 只是框架图（灰盒 + 文字），不是美术，没改 Swift。和 GPT 讨论过一轮。图里的名字、留言都是占位，正式版只用真实数据。

一句话：现在的问题是题目、入选、右页照片三者没连起来——看得出“有活动”，看不出“谁在回应它”。四版各试一种思路，第五版 E 是我和 GPT 都推荐的合并方案：左页把一道题整张展开、写出真实的人名，下面放本周入选；右页只放这道题的投稿。

五版一览

版思路题目突出“有人在”的感觉人少时GPT 排序
A 期刊一次展开一个题最强中（名字 + 留言）右页可能空2
B 名册左页列题目、胶卷房间、留言中中（名字多）最容易显空3
C 题目墙每题一列强强（同题并排）很空5（只适合做选题页）
D 近况按时间的对话流弱最强冷清但诚实4（适合当“大家/关注”的排法）
E 同题共拍A + B 合并强中上站得住1

A 期刊式：每次只展开一个题目

  1. 侧耳切 今日 / 本周 / 限定 / 往期；同一组里有多题时耳下再列题名。
  2. 题目“封面”：题名、一句说明、截止、已投的人名，右下“投一张”。
  3. 本周入选：3 张小图 + 作者（你在看板上选的左页内容）。
  4. 大家在说：两句最新的真实留言，点了跳到那张照片。
  5. “我的”收成一条：连续天数、待审、新消息；点开占两页。
  6. 右页只放这道题的投稿；有留言的照片下露出一句。
适合题目最突出，像一期期主题活动（最贴近你做活动的经验）；引导“今天拍什么”。
牺牲随便逛大家作品、按胶卷看效果的入口变弱；一次只展开一个题。
人很少时封面靠文字撑得住；右页投稿少时会空——用“这里可以是你”空位，不拿别题作品补。

B 名册式：左页列出房间和里面的人

  1. 这期在拍：进行中的题目各一行，带截止和最近投稿人的名字，各自能“投一张”。
  2. 胶卷房间：每卷一行，有新作品打红点，写最近一位和时间；没动静的收进“全部 16 卷”。
  3. 本周入选：小图 + 作者。
  4. 最近的留言：一两句真实留言摘录。
  5. 我的：一条状态。
  6. 右页跟着左边选中的范围走；作品不够时，用写明“官方”的分隔纸接官方选片。
适合多题、多卷同时有动静时一眼看全；最像 Discord / 图虫圈子；把胶卷当成社区单位（调研报告的推荐）。
牺牲左页文字密，像目录；题目不如 A 突出；照片和对话分在两页。
人很少时最容易显空：16 卷里大多写着“上周”“还没有”。GPT 认为人少时不该建胶卷房间（见下面讨论）。

C 题目墙：每个题目一列，投稿钉在下面

  1. 顶条：进行中题目数、胶卷筛选、本周入选入口、我的。
  2. 每列一个题目：题卡在上，大家的投稿钉在下面，“投一张”在题卡上。
  3. 右边露出“往期”，横滑看更早的题目。
  4. 我的：顶条右端。
适合多题并行时比较“今天想拍哪题”；一眼看到每题有谁回应；节日限定题有存在感。
牺牲打破“右页只放相册”的已定规则；照片小；竖屏只能一次一题左右滑，其实是另一种结构；胶卷筛选藏得深。
人很少时最空：某列 0 张、三列高低不齐，冷清一目了然。

D 近况式：按时间看谁说了什么

  1. 题目缩成一张小卡，带“投一张”。
  2. 近况流：留言、回复、入选公布、新题开始，只写已经公开的事，带时间。
  3. 我的：一条状态。
  4. 右页按公开时间排的作品，大图 + 作者 + 第一条留言；可切 全部 / 关注。
适合最能看出“有人在说话”；熟人、关注流最舒服；时间感最强。
牺牲题目退成小条（和你“突出话题”的要求相反）；像通知列表；同一件事左右两边各出现一次。
人很少时时间会拉长成“3 天前”“上周”，诚实但冷清；没有留言时只剩系统事件。

E（推荐）同题共拍：A 的题目主轴 + B 的清楚切换

  1. 顶耳 题目 / 大家 / 关注（之前已定的三个范围），默认在“题目”。
  2. 选中的题目整张展开：题名、说明、截止、最近公开的人名、“投这题”。
  3. 其他进行中的题目各一行（本周、限定），点一下就换成它展开，右页跟着换。
  4. 本周入选：2×2 小图，写作者和来自哪题；“看全部”在右页打开入选作品。
  5. 胶卷筛选和往期题目收成两个小入口，不占大块。
  6. “我的”改成名牌：头像、昵称、连续天数、待审、未读；点开占两页。
  7. 右页只放当前题目的投稿；只有真有留言的照片才露出一句，没有就不留位。
适合题目最突出，同时多题并行也看得到；“大家在拍同一道题”最清楚；本周入选跨题发现；左页上下都有内容。
牺牲按胶卷逛退成筛选；“大家/关注”要多点一下；时间线式的热闹感比 D 弱。
人很少时题目卡和入选区靠真实少量内容就站得住；某题 0 张时右页写“还没人投，第一张可以是你”，不悄悄补别题作品。

为什么推荐 E

  • 你要的“突出话题”：题目整张展开，字最大；其他并行的题也露在下面，不用猜。
  • “人聚在一起”：人名写在题目里（谁回应了这题），留言挂在具体照片下，本周入选写作者。都是真实数据，人少也不造假。
  • “左上满下空”：左页从上到下是 题目 → 其他题 → 本周入选 → 小入口 → 我的，没有空出半页。
  • 层级：只有一张“选中”的题卡是亮的；本周入选次之；筛选和我的最轻。纸可以做薄（这是美术阶段的事，框架里只用细线）。
  • D 的对话流不丢：放进“大家 / 关注”范围里当作品排法（右页大图 + 留言）。

和 GPT 讨论的结果

话题结论
主方案一致：推荐 E（GPT 提出的合并方案，我同意）。GPT 排序 E ＞ A ＞ B ＞ D ＞ C。
C 题目墙一致：不做主页；以后可以当“选题页”（点往期或更多题时打开）。
D 近况一致：不单独做首页；“大家 / 关注”范围用 D 的右页排法。点赞、入选不各生成一条动态，免得同一件事重复。
本周入选采纳 GPT：A 里原来写的“本期入选”改回你选的“本周入选”；要有小图和作者，不只列名字。
胶卷房间有分歧：GPT 认为人少时胶卷房间会变成一长串冷清区，只做筛选。调研报告认为胶卷是唯一自动准确的社区单位。我在 E 里先听 GPT 的（收成筛选），保留 B 给你对比；等作品多了再考虑把筛选升级成房间。
作品不够时补什么采纳 GPT：不把别的题或官方作品悄悄混进当前题目；E 里改成写明“还没人投”。B 里那张“以下是 Koco 暗房选片”分隔纸是 B 自己的做法，选 B 才用。
“首屏三个名字一句留言”一致：是内容够多时的检查标准，不是固定坑位；没有留言时不留空位，结构照样成立。
竖屏一致：不把左页整块堆在照片前面；题目卡和入选条往下滑时收起。
