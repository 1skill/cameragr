**现在最大的问题不是“拟物还不够”，而是同一件物品承担了几种互相冲突的导航含义。** 海报、九宫格、信封、范围吊牌都在指挥右页，却没有主次。把方块换成胶卷罐，只会得到更拥挤的相机包。

四张图里，主页的相册最成立；看片页把相册变成了网页弹层；作者页把主页控件原封不动留下；“我的”则是一张覆盖相机包的账户设置表。建议按 **①范围结构 → ②主页 → ③看片 → ④作者与我的** 的顺序重做。

以下是设计提案，只针对 Duo 展开横版；未改文件。

**A．先确定用户到底在看什么**

按预期使用频率排序，后续应以实际使用验证：

1. 看照片，找到喜欢的画面与胶卷效果。
2. 看今天的题目，投一张自己的照片。
3. 点赞、留言，继续看这位作者。
4. 看关注作者的新照片。
5. 收来信、看互动、领连续投稿奖励。

范围只保留这一套关系：

| 层级 | 内容 | 规则 |
|---|---|---|
| 三个并列入口 | **题目／大家／关注** | 同时只能选一个 |
| 题目内部 | 今日、 本周、往期具体题目 | 选定题目后才显示其照片 |
| 二级筛选 | 胶卷 | 在当前范围内筛选，不另开“房间” |
| 临时深入 | 作者 | 从照片进入，返回恢复原范围、胶卷、滚动位置 |
| 个人空间 | 我的 | 自己的作品、消息、信件、奖励，不与公共范围并列 |

例如左页始终明确写：

> 今日题目「它睡着了」  
> 胶卷：不限

或：

> 关注作者的新照片  
> 胶卷：Porto 400

**取消“房间”的叫法，取消另外一张重复解释范围的吊牌。** 范围直接写在控制右页的物件上。

往期题目放在题目夹后方露出的 **“往期”纸耳**。打开后仅左页换成按日期排列的题目索引纸，右页仍是当前相册；选择历史题目才更新右页。结束的题目显示“已结束”，不保留有效投稿入口。

**B．逐页布局与操作**

**1．主页左页：一个征集夹，一组索引，一只个人口袋**

沿用现图约三成宽的左侧工作区；相册继续越过书脊占据其余部分，不强行左右各半。

- **上部约一半：征集夹。** 保留黄铜夹与纸张叠，但缩小示例照片，让题目、简短说明、截止信息可读。纸面下缘印“距结束 8 小时 · 128 人参与”；只用真实可公开数据，不显示投稿总数与公开数的差额。
- **夹顶：三个宽纸耳“题目／大家／关注”。** 当前纸耳向前突出，纸张露出完整标题；其他两枚退在后层。选中同时有位置变化与文字，不靠红色。
- **题目模式：** 纸张侧边露出“今日／本周／往期”纸耳；不再用两颗铜钉暗示可切换。选“大家／关注”时，海报位置换成简洁的范围说明纸，不继续摆题目海报。
- **中部：胶卷索引带。** 不摆九个同等大小的物件，也不放一排立体胶卷罐。使用收在浅皮套中的窄索引签，显示“不限”和少量卷名；上下滑动可看全部。选中的签向右抽出少许，并露出红色短线；上沿固定显示当前卷名，滑远也不丢状态。
- **下部：薄个人口袋。** 只露出“我的 · Koco”姓名签和来信角，有未读时增加小蜡封；缩掉现有大信封。
- **投稿入口：** 征集夹右下伸出一枚清楚写着 **“投一张”** 的厚纸舌。只属于当前开放题目；在“大家／关注”下写“选题投稿”，先选题再进投稿夹。
- 底部长铜窗保留，位置、尺寸三页一致。

这样浏览、筛选、投稿分别有固定位置，不必让用户猜下一次点纸牌会不会换题。

**2．右页相册：保留最好的部分，修正内容状态**

保留透明插袋、黑色背衬、缝线、随行铜环，以及纵向浏览。

- 照片保留原比例，完整放入插袋；不同画幅自然露出部分黑色背衬，不统一裁掉主体。
- 袋底窄纸签只写 **作者 · 胶卷**；右端留点赞标记与数字。整张照片打开看片，作者名进入作者页，赞有独立触摸区。
- 普通浏览不增加横幅、留言摘录或推荐卡。
- 加载更多只发生在底部；已有照片保持可看。
- **真空态：** 第一排插袋放一张简短说明纸，其余口袋自然结束，不铺满四排空袋。
- **首屏加载：** 一张“正在取照片”的暂存纸；不要用空袋伪装加载骨架。
- **失败：** 原位置出现“照片没取到 · 重试”纸签；底部分页失败不盖住前面的照片。
- **到底：** 最后一排之后露出插页的实体下缘，表达“结束”。

**3．看片：照片在左，背面批注在右**

不继续用深黑遮罩叠两张悬浮卡。打开照片后，形成一次完整的 **看片展开状态**：

- **左侧约六成：** 一张放大的照片，由四枚薄相角固定在深色底衬上；相角只压住极小边缘。不要强加厚白边，也不要增加滤镜。
- **右上：** 一条照片背签，放作者名、胶卷、所属题目、日期；作者名可点。点赞是可按压的小心形金属章，旁边显示数量。
- **右中：** 一张有横线的批注纸，留言按行排。长内容在这张纸内滚动，不为每条留言再造一张卡。
- **右下：** 批注纸末尾留“写一句……”空行，点后输入；右端独立纸舌写 **“留一句”**。键盘出现时，输入行始终在键盘上方；纸面明确露出“收起键盘”小签。
- **右上外缘：** 固定“收回相册”纸耳；旁边较小的“铺开看”纸耳负责全屏。全屏仍有可见返回入口。
- **安全操作：** “处理”小纸耳展开一张短处理单，明确写“举报照片／屏蔽作者”；留言长按后也显示带文字的处理单，不能只依赖隐蔽手势。

左右滑换同一范围的照片；回相册恢复原位置。无留言显示“还没有留言，留第一句”；发送中显示“正在送出”，网络失败保留文字并提供“重送”。自己的内容成功送达后正常呈现，不通过纸色、章或数量泄露审核状态。

**4．作者页：左边只讲这个人，右边只放这个人的作品**

- **左上：** 保留档案纸夹的材质，取消大信封盖。放头像或首字章、昵称、两行简介、“多用 Porto 400 · 拍过 3 种胶卷”；不显示关注数。
- **左中：** 一枚可抽动的关注纸签，“关注”变为“已关注”，纸签推进固定带内。动作可逆，不能画成盖下后无法理解如何取消的永久章。
- **其下：** 互关后出现一枚插在浅袋中的信纸角，写“写信”；尚未互关时写明“互相关注后可写信”，不隐藏原因。
- **左下：** 显眼的“返回原相册”纸耳；另设始终可达的“处理”签，展开后提供举报、屏蔽。不会被信封遮挡。
- 删除主页九宫格、题目海报、“我的”信封，不在作者页再开一套筛选。
- **右页：** 同一相册结构。只有一张作品就只保留第一排插页，下缘可见；放一张小纸签“公开作品 1 张”，不要留下整页似乎等着加载的空袋。

加载、失败分别写在档案纸与相册对应位置；失败时保留返回入口。进入自己的作者页则显示“编辑简介”，不出现关注自己或写信给自己。

**5．我的：让相机包保持展开**

取消覆盖两页的巨幅纸板，改为：

- **左上：** 姓名纸签、简介，可点对应文字编辑。
- **左中：** 一条窄奖励纸带，显示连续投稿天数、下一档限定卷；达标后露出“领取”兑领签。仅显示服务端已确认的奖励，不显示审核进度或解释其与投稿数的差异。
- **左下：** “新消息”“信件”两枚收纳纸耳；账户操作收在“账户”薄折页里，里面明确列出规则、退出登录、删除账号。删除需另一次确认。
- **右页默认：** 自己的照片插页，沿用公共相册的操作。
- 选“新消息”时，右页换成按日期记录的通知纸；选“信件”时换成信纸夹，选收信人后展开通信纸。
- 未读用小蜡封并配“未读”文字；真正显示过的条目才去掉。无消息、加载失败各有明确纸面文案。

“我的”退出后回到进入前的社区位置。未登录时，左页提供清楚的“通过 Apple 登录”，不能把身份授权藏成需要猜的图案。

**6．投稿夹：从题目出发，投完回到原处**

- **左页：** 当前题目说明、截止时间；下方一句话稿纸。换题需点题目纸耳，不在照片选好之后悄悄改变题目。
- **右页：** 自己的 Koco 照片插袋；点选后，该照片露出“已选”纸角，其他照片不变暗成网页选图器。
- 选定后右页展示大预览，左下伸出“投这一张”纸舌；投稿前可回照片插袋重选。
- 成功后收回投稿夹，回到原题相册，自己的照片正常出现；不盖“待审”章。
- 无可选照片时放“还没有 Koco 照片”说明纸和“去拍一张”纸舌。上传中防重复点，网络失败保留照片与文字，原纸舌改为“重试投稿”。

**C．GPT 美术清单**

比例指单件素材包围框；先用实际布局确定触摸尺寸，再出素材，不用厚装饰挤压文字。

| 新画部件 | 比例 | 描述与用途 |
|---|---:|---|
| 精简征集夹 | 约 4:5 | 黄铜夹固定薄纸叠，预留标题、时间、人数与投稿舌位置 |
| 范围纸耳组 | 单枚约 3:1 | 题目／大家／关注共用，提供前伸与后退两态 |
| 题目索引纸 | 约 4:5 | 今日、本周、往期的同一纸夹体系，不另造导航器 |
| 胶卷索引皮套与签 | 皮套约 3:2 | 窄纸签可抽出，普通、选中两态共用同一轮廓 |
| 个人浅口袋 | 约 4:1 | 露出姓名签和来信角，替代大“我的”信封 |
| 看片相角与底衬 | 相角约 1:1 | 四角独立透明素材，可适应不同照片比例 |
| 批注纸与输入纸舌 | 约 3:4 | 低纹理横线纸，下缘留书写区与发送动作位置 |
| 通用动作纸耳、金属赞章 | 约 3:1、1:1 | 返回、全屏、处理、投稿等复用；提供按下状态 |
| 作者档案纸 | 约 4:5 | 无遮挡信封盖，预留简介、关注签、信纸角 |
| 连续投稿兑领纸带 | 约 4:1 | 数字与奖励动态填入，未达标、可领、已领三态 |
| 投稿夹内衬 | 单页约 3:4 | 与现有包内衬一致，承载题目、稿纸和照片选择 |

**直接复用：** 皮包外壳、长铜窗、铜轨与随行环、透明插袋、照片标签纸、现有小蜡封、已画好的信纸。征集海报的纸纹与黄铜夹可复用，布局需重组。

所有可见物件由 GPT 提供；昵称、题目、计数和本地化文字由代码排入留白，避免把文字烘焙进美术。并非每次操作都需要新造一种道具。

**D．三张可直接交给图像模型的提示**

**① 社区主页**

> 1456×1024 横版，折叠 iPhone Duo 完全展开后的 Koco 社区界面，正面俯视，真实旧棕皮相机包两页展开。沿用参考图的包壳、皮纹、黑色衬里、铜色活页机构和底部长铜窗，导航文字“胶卷／社区／设置”，短红针在社区下方。左侧约占宽度 29%，右侧照片插页越过书脊占其余空间。左上一个精简黄铜征集夹，顶端三枚实体纸耳“题目／大家／关注”，题目纸耳前伸；纸面小幅示例照片、清楚标题“它睡着了”、一句说明、“距结束 8 小时 · 128 人参与”；侧边露出今日、本周、往期纸耳，下缘露出“投一张”厚纸舌。左中浅皮套装窄胶卷索引签，当前“不限”向外突出，少量卷名可见；左下薄个人口袋，露出“我的 · Koco”姓名签和小蜡封。右侧三列透明照片插袋，展示不同作者的丰富日常摄影，每张下缘细纸签写作者与胶卷，细小心形赞章。无九宫格按钮，无胶囊、浮动卡片、额外标题横幅、装饰钉或底部新菜单。材质真实但文字区平整清晰，控件有可触摸尺度。

**② 看片**

> 1456×1024 横版，Koco 折叠 iPhone Duo 展开相机包的看片状态，保持两页实体包结构与底部长铜窗，不使用黑色遮罩或悬浮网页弹窗。左侧约六成是一张完整展示的横幅照片：窗边人物手持杯子，窗框阳光落在墙上；照片以四枚极薄相角固定在深色内衬，主体无遮挡，不加厚白边。右侧上部一条照片背签，作者 Momo、Porto 400、题目、日期，小心形金属赞章及数字。右侧中下部一张低纹理暖纸批注纸，三条短留言沿横线自然排列，底部空行“写一句……”及明确的“留一句”纸舌。右上固定“收回相册”“铺开看”纸耳，旁边较小但可见的“处理”纸耳。人物照片为主，留言可读，纸张与皮革有克制层次。没有白色输入框、粉色发送胶囊、三个点图标、巨大关闭文字、厚重相框或多张留言卡片。

**E．我不同意的几处**

- **矩形照片本身不是网页感的来源。** 照片本来就是矩形；关键是有没有与相册一致的承载关系。四枚相角足够，不必给每张图加厚边框。
- **留言共用一张纸是对的。** 问题是当前内容、输入与动作挤在一起；逐条拆成纸卡反而会变成拟物卡片流。
- **一个作品的作者不该被“补满”。** 空袋可以真实存在，但要让用户看见页尾并知道只有一张，不能伪装丰富或制造加载悬念。
- **不是所有动作都该变成印章。** 关注可取消、筛选可切换，抽签更符合行为；印章适合点赞反馈、领奖完成这类确认感。
- **参与人数不是最优先缺口。** 截止时间和往期入口直接帮助行动；人数可作为小字，不能挤走题目与投稿入口。

先把“当前范围、当前胶卷、返回位置”三件事做清楚，再画新物件。否则美术越精细，用户越难分辨哪些真能操作。
