**首选：第三组双页做一本自己的摄影小册，页签叫「小册 / BOOK」。** 现有相机包已经摆满胶卷、吊牌和照片套，再塞活动入口会更难找；独立跨页最清楚，也能复用现有翻页机制。

我与讨论稿有三处分歧：

- 旧稿的“七天、不连续”已被用户决定替代：**首期连续三天，以后每期连续十四天**。
- 十二月先叫“小册”，不叫“同好”：现在没有其他人的内容，不能让入口暗示已有社区。
- **不加出片夹第四档。** 视频、来信、照片是导出形式；放入小册是收藏动作，混在一起不好理解。

以下是文字定案建议；未修改文件，未做真机交互验证。

**1．位置，按优先级**

1. **第三组双页：胶卷 → 维护 → 小册。** 将来真正社区上线，第三签再改「同好 / CLUB」，小册留在其中。
2. 回看照片边缘放一枚「放进小册」纸耳，作为快捷入口。
3. 不建议放维护夹，也不建议拍完自动弹出活动。

当前 `Spread` 实际只有 `.films / .kit`，第三组需要新增。

**2．一天怎么算**

- **同一天用 Koco 实拍、保存成功，再主动放进小册一张，才算参加。** 免费卷即可完成；导入照片套滤镜不算，不要求公开分享，不识别狗狗是否睡着。
- 首次放照片时开始计数；每天最多一格，当天可以换照片。
- **首版用开始时的本地时区，整期固定；公历零点换日。** 纸上明确写“按开始时所在地时间，每天零点换一天”。旅行中不随系统时区改格子。
- 用拍摄时刻归属日期，保存结束时刻不决定日期；**零点前拍、零点后才放入，不算前一天**。这条要在规则里说明。
- 相邻日期差一天才延续；差两天及以上，下一次参加从第一天重算。
- **不补签、不收费续签。** 漏拍只重算连续天数，旧照片仍夹在前页；文案：“隔了一天，今天重新开始。前面的照片还在。”
- 无倒计时、失去奖励提醒或活动截止日。完成后领奖资格一直保留。
- 日期倒退不重复推进；纯本地接受少量改钟作弊，不为一卷赠礼增加联网验证。

**3．双页长什么样**

统一以 **1456×1024** 为美术画布，坐标为左上角 `x,y,w,h`；书脊约 `x=728`。每页最多三件主要物品。

纸张、封面、袋子、印章均由 GPT 出分层素材；代码放真实照片、本地化文字和触摸区。实际触区至少 44 pt。

**4．奖励：Porto 400，`id: portra400`**

首选它：柔和、暖而不过分浓烈，适合毛发和室内生活照，也与当前相机包里的介绍一致。**这是风格选择，不把模拟 ISO 当作提升暗光拍摄能力。**

- 未拥有：获得这卷的本地持续使用权，不限三张。
- 已买单卷／已买全部胶卷：领取同样的**首期纪念封套＋完成日期章**，不换其他卷、不补试拍次数。
- 所有人完成后都得到纪念物；开始前就写明已拥有者的奖励。
- 全胶卷购买仍包含未来胶卷，不能因活动另设成像权限门槛。
- Porto 的购买纸签同时提示“也可连续三天参加小册获得”。

**5．放照片：小册空位选片第一，回看快捷第二**

**首版必做：点空位，右页翻出一张“今天拍的”接触印样。** 只展示当天合格的 Koco 实拍，点照片后露出「夹进小册」纸签，确认才计数。没有照片时写：“今天还没拍，合上去拍一张吧。”

回看边缘的「放进小册」纸耳可后补；出片夹保持现有三档。不要打开整个系统相册让用户自己找，也不要把浏览照片直接算作参加。

**6．审核与恢复**

**我的判断：可以按 App 内创作奖励提交，但不能保证获批。** Apple 3.2.2(x) 允许激励特定 App 内行为；3.1.1 同时约束数字功能解锁。保留正常 IAP 购买，不做外部支付、兑换密钥或推广任务，并向审核完整披露。[Apple 审核指南 3.1.1、3.2.2(x)](https://developer.apple.com/app-store/review/guidelines/)

审核备注说明：

> 小册是完全本地的摄影活动。用户连续三个日历日，各拍摄、保存并选入一张照片，可免费获得 Porto 400 滤镜使用权。免费滤镜即可完成，无账号、上传、评分、下载、邀请、分享或外部支付要求。Porto 400 同时通过非消耗型 IAP 出售。赠礼独立于 StoreKit 交易记录。

另外提供**第三页签的进入步骤、三天流程录像和领奖结果**，不要让审核员自行改系统时间测试。

开始纸条及维护夹的恢复说明统一写：

> 小册和活动赠卷保存在本机。恢复购买只恢复 App Store 买过的胶卷，不能找回丢失的活动记录。卸载或换机后，活动赠卷可能丢失。

不承诺换机恢复或家庭共享；设备备份能否带回记录也不作为保证。

**7．首版范围与最小数据**

**必须做：** 第三跨页、今日选片、连续三天规则、断签保留照片、一次性领取、已拥有者纪念物、恢复说明、本地化、锁屏拍摄归档与赠卷权限同步。

**后放：** 回看快捷纸耳、整册导出、十四天活动内容、社区、账号、云同步、多册书架和复杂拆袋动画。数据支持十四天，十二月不用同时制作第二期。

建议新增 `BookStore`，原子写入 `Application Support/books.json`：

```text
schemaVersion
issues[id]:
  requiredDays                // 首期 3；以后 14
  rewardFilmID                // portra400
  startedAt, timeZoneID
  entries[]:
    shotID, capturedAt, dayKey, addedAt, attemptID, thumbnailPath
  completedAt?
  claimedAt?
grants[issueID]:
  filmID, grantedAt
```

连续天数从日期和本轮记录推导，避免另存计数漂移；旧轮记录保留。收藏时保存一份册内缩略图，系统相册删图后仍保留纪念，已完成进度不倒扣。

现有 `ShotLog` 只有照片 ID、胶卷和日期，**要补拍摄来源及真实快门时间**，不能只凭“在日志里”认定实拍。锁屏导入也保留这些字段。

`FilmStore.isUnlocked` 增加本地赠礼判断；**不把赠卷塞进 `owned` 或改试拍次数**。购买刷新、恢复购买不清赠礼，锁屏 `CaptureContext` 单独传赠卷字段。领取记录与赠礼一次落盘，失败就保留“可领取”状态。
