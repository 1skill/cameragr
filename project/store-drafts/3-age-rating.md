# 年龄分级依据表 · 待确认稿

> 旧版不带社区，评为 4+。**加了社区之后不能直接沿用 4+。** 下面按年龄分级问卷常见的题目，整理了社区版的现状和依据。问卷以 App Store Connect 当时的版本为准，**最终答案由你选**。

| 题目（大意） | 现状 | 依据 |
|---|---|---|
| 用户生成内容（UGC） | **有**：照片投稿、文字、留言 | C3/C7 |
| UGC 是否在公开前审核 | **是**：照片和留言都要人工审核后才公开 | “先审后公开”，用户 11/24 定；服务端 pending 状态 |
| 有没有举报和拉黑 | **有**：照片、留言都能举报，三人举报自动隐藏；拉黑后双方互相看不到 | C2c、C7 |
| 内容过滤 | 有基础的敏感词过滤，并禁止链接 | worker.js BLOCKED_WORDS、链接检查 |
| 用户之间能否私信 | **不能**：没有私信，只有照片下面的公开留言 | — |
| 能否分享位置 | **不能**：投稿时去掉 GPS | CommunityPhoto |
| 暴力、色情、恐怖、赌博、药物等内容 | App 本身没有；社区规则禁止，审核时拦下 | 社区规则第 2 条 |
| 无限制访问网页 | **没有**：App 里没有浏览器 | — |
| 应用内购买 | **有**：胶卷单卷购买和全部胶卷 | StoreKit |
| 抽奖或战利品箱 | **没有**：奖励按连续打卡天数固定发放，没有随机成分 | C5 |

**建议**：问卷里如实勾选“有 UGC，且有审核、举报、拉黑”。至于最后落到 12+ 还是 13+（以当时的档位名称为准），**由你根据问卷结果决定**。我不预先替你选。

- 隐私政策里“儿童”一条写的适用年龄，要和这里的分级一致。
